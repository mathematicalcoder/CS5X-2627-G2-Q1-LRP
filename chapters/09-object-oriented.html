Introduction: Classes and Objects

        
Procedural programming split a program into various functions that operate on data stored in variables. While beginner-friendly, as programs scale, it gets increasingly inefficient; changes may require editing multiple lines of code and data may be accessed globally. Object-Oriented Programming (OOP) introduces an efficient way to structure numerous functions and variables, and focuses on two concepts: classes and objects.

        
Class - defines a template or category for the creation of objects (Ex. Subjects)

        
Object - instance of a class that has unique attributes (Ex. Biology, Chemistry, Physics)

Four Pillars of OOP

        
OOP has four pillars that distinguishes it from procedural programming: Encapsulation, Abstraction, Inheritance, and Polymorphism.

        
Encapsulation

        
This involves grouping methods in a class while restricting access to some data by using private attributes.

        
Abstraction

        
This focuses on hiding complex logic behind a clear interface. It is abstracting more complicated details to focus on the necessary functions.

        
Inheritance

        
This allows a class to share properties and methods from another class. The subclass inherits certain aspects from a parent class.

        
Polymorphism

        
This enables different classes to have different behaviors with the same method name. It allows a single interface to handle different object types.
