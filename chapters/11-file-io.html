File Input/Output

Written by Lawrence Cereñado

📁 File I/O

Let's say that you have an important text file that you want your Python program to handle. You would be in luck, as Python supports file input, handling, and output! Python can handle the following file operations:
  • Read a file
  • Write to the file
  • Close the file


Reading the File

The first method in dealing with a file in Python is to read the file. The syntax for this is: file.read(size) Where file is the file to be read, and size is how many bytes your program would read. For example:
places = open("data/favPlaces.txt")
print(places.read()) This returns our favorite places:
Boracay
Laguna
Pampanga
Baguio

Reading Methods

Aside from the .read() method, the .readline() and .readlines() methods are also other ways to read the file. The former reads the first line of the file until it reaches the end of the file. The latter returns a list of all the lines of the file as strings. For example, for our file earlier, doing the latter method would return this: ['Boracay\n', 'Laguna\n', 'Pampanga\n', 'Baguio\n'

Creating a File

You can create a new file (if it doesn't exist), using the .open() method, with the file access method set to 'x'. It would have nothing inside of it initially though.

Modifying a File

As we discussed earlier, there are two types of file modification methods. We can choose to append to the file, or write (overwrite) the file with new content. This is done using the .write() method.
If we choose to append:
The syntax is : file.write(str), where str contains the content we want to append. For example, if we want to add Bulacan to our list:
open("data/favPlaces.txt", "a")
file.write("\nBatanes")
We add an '\n' symbol to separate it from the other lines already there.

If we choose to write:
We also use the same method, but with a different access mode. open("data/favPlaces.txt", "w")
file.write("\nBatanes")
Now our favorite place is just Batanes.
