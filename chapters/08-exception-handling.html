Types of errors


        
In Python, we have two types of errors:
        
    
            
  • syntax errors (SyntaxError), meaning there is something wrong in the format of the code (e.g., indentation, missing colons, etc.), and
    • 
            
  • semantic errors, which depend on the context of the code and how it is being executed (for example, division by zero gives a ZeroDivisionError).
